# 🍕 Pizza Sales Analysis & Power BI Dashboard

## 📌 Project Overview

This project presents an end-to-end analysis of pizza sales data using MySQL, SQL, Power BI, Excel, Power Query, and DAX.

The objective was to analyze sales performance, order trends, product performance, pizza categories and sizes, and identify key business insights through interactive Power BI dashboards.

### Data Analysis Workflow

Raw Data → Data Preparation → MySQL → SQL Analysis → Power BI → Dashboard → Business Insights

---

## 🛠️ Tools & Technologies

- MySQL
- SQL
- Power BI
- Microsoft Excel
- Power Query
- DAX
- CSV

---

## 🎯 Project Objectives

- Analyze overall sales performance
- Measure total revenue and total orders
- Analyze total pizzas sold
- Calculate average order value
- Identify daily and monthly order trends
- Analyze sales by pizza category
- Analyze sales by pizza size
- Identify top-performing pizzas
- Identify low-performing pizzas
- Create interactive business dashboards
- Generate actionable insights from sales data

---

## 📊 Key KPIs

- Total Revenue: 697.05K
- Total Orders: 18,180
- Total Pizzas Sold: 42,258
- Average Order Value: 38.34

## 🔍 Key Insights

- The business generated approximately 697.05K in total revenue.
- A total of 18,180 orders were recorded.
- 42,258 pizzas were sold across the analyzed period.
- The average order value was 38.34.
- Large-size pizzas represented the largest share of pizza sales by size.
- Classic pizzas contributed the highest category sales share.
- The Classic Deluxe Pizza was among the strongest performers by quantity and total orders.
- The Thai Chicken Pizza generated the highest revenue among the top-performing pizzas shown in the dashboard.
- The Brie Carre Pizza was among the lowest-performing pizzas by revenue and quantity.
